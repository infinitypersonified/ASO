# ÀṢỌ House — Worn Like a Story

An Afrocentric contemporary fashion-house portfolio concept built with React 19 and Vite. This redesign uses an editorial identity distinct from FORM / SPACE: Bodoni Moda, Syne and DM Mono; warm paper, signal red, indigo and acid-lime; a typography-led cinematic opening; scroll reveals; kinetic ticker; parallax image movement; asymmetric fashion editorial layouts; product detail overlays; and a functional front-end demo bag.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Notes

- Product bag and product detail overlays are front-end portfolio interactions; no checkout or payment processing is connected.
- Fashion/editorial photography and Google Fonts load from external URLs, so an internet connection is required for those assets.
- The sample studio email is `studio@aso.example`; replace it before publishing.
- Includes responsive mobile layouts and `prefers-reduced-motion` support.
